# Lampas

A licence-gated progressive web app for reading the New Testament in Koine Greek: the Byzantine text beside the Majority Standard Bible, the words you know woven into the English as Greek, a tap on any word for its form and meaning, and a tutor on the verse.

Built by the millwright factory. Texts: Majority Standard Bible tables (public domain, majoritybible.com); lexicon: STEPBible TBESG (CC BY 4.0).

# Which Robinson-Pierpont edition the Greek follows

Generated by `npm run greek:edition` (`scripts/greek-edition.ts`). It needs the network and rewrites this file; do not edit it by hand.

## Verdict

Edition: 2005

**The Greek of the MSB tables (<https://majoritybible.com/msb_nt_tables.tsv>) follows the Robinson-Pierpont 2005 edition.** Of the 6 places where RP2005 and RP2018 differ in more than punctuation, the table has the 2005 reading at 6, the 2018 reading at 0, and neither at 0.

How it was found:

- RP2018 is the repository <https://github.com/byztxt/byzantine-majority-text> at tag `v3.3.2` (`csv-unicode/ccat/no-variants`, with the Pericope Adulterae and Acts 24:6-8 from their own files).
- RP2005 is the same repository at tag `v2.0.3` (`csv-unicode/accents/no-variants`): its README names release 2.0.3 as the one closest to the 2005 text.
- The table is `msb_nt_tables.tsv`, its "MT Greek" column, each verse's words in Greek order.
- Each verse of the table is lined up with the same verse of an edition word by word (words with the same letters, ignoring accents, breathings and case, are matched; the words between two matches are paired in order). Every word that differs is counted once, by the most basic difference, in the order of the list below.
- Everything is in NFC. The elision apostrophe is one character in both. Punctuation is taken off each word and compared apart.

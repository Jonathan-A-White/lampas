# Lampas best-practices audit

Written 2026-10-10 at base commit 921874d (version 0.1.27, mw-vtjxh4.25). Docs only: no behaviour changed.

Why it exists. The Governor, Postern general, 2026-10-09 18:37Z: "don't forget all my apps they should all be on Jonathan a white you know my GitHub will you bring them up to best practices that we've spoken about". This is the first step for Lampas: every line of the vault's PWA checklist (`seats/builder/pwa-best-practices/checklist.md`, 31 lines) and every rule the vault's changelog placed on 2026-10-09 and after, each marked pass, fail or n/a with its evidence; each failure carries the smallest fix and its size; section 3 ranks the failures into at most ten stories the Mayor can file. Lampas is one PWA (a Vite app served from `https://lampas.allmymind.org`); it has no Android app and no Python server, so no row is n/a for that reason.

How to read it. Status is `pass` (the rule holds and the evidence shows it), `fail` (a part of the rule is broken or missing: the evidence names it) or `n/a` (the rule does not apply to Lampas, or only a real phone can show it: said in the evidence). Evidence is a `path:line` that exists at the base commit, a command and what it printed, or the reason. Size of a fix: XS a few lines in one file and its test; S one story, one or two files and a scenario; M one story across several files or a new component; L split it first. A row that fails in two ways has one fix that names both.

It is a dated snapshot of base commit 921874d: line numbers move as the code does, so a cited place is true at that commit only (section 4 has the shell loop that checks them there). It holds 31 checklist rows C1 to C31, a status and evidence on every row, a fix and size on every `fail`, and at most ten ranked stories each with an acceptance check.

## 4. How the citations were checked

Every backticked `path:line` and `path:line-line` above was checked at the base commit with this shell loop, run from the repo root (it prints nothing when every cited file exists and is at least as long as the cited line):

```sh
grep -o '`[A-Za-z0-9_./-]*\.\(ts\|tsx\|css\|html\|md\|json\|feature\|toml\|mjs\):[0-9]*\(-[0-9]*\)\?`' docs/best-practices-audit.md | tr -d '`' | sort -u | while IFS=: read -r f l; do
  last=${l##*-}; test -f "$f" && test "$(wc -l < "$f")" -ge "$((last - 1))" || echo "bad: $f:$l"
done
```

That a place exists does not prove the claim beside it: the claims were each read in the file at the base commit, and the live ones (the 404, the HSTS header, `sw.js`) were asked of `https://lampas.allmymind.org` on 2026-10-10.

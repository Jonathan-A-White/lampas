# Layout: Memorize

Which file holds what for Memorize, the app's help to learn Bible verses by heart (mw-6ww.137, the epic mw-fu7dqf). A story that adds a file of `src/memorize/` writes its line here, in the same form (the path, then `#` and what it holds; a continuation line starts `#   `), never in CLAUDE.md.

```
src/memorize/refs.ts    # versesOf(canonical) -> the verses 'Rom.8.28' / 'Rom.8.28-29' names, each its own Verse of the chapter (never a passage Verse), with the heading and the chapter;
#   {ot: true, heading} for an Old Testament reference (Lampas has no Old Testament text); null for a string that names no verse (verse 0, a verse the chapter lacks); a chapter alone is its first verse
src/memorize/target.ts  # tokensOf(verse, 'en' | 'el' | 'weave', woven?) -> Token[] {text, lang, chunk, word?}: English words in English order, Greek words in Greek order, or the weave's drawn order
#   (a woven chunk's Greek as 'el', every other chunk's English as 'en', a moved closing mark kept); memorizeTarget(canonical, lang, readerSettings?) joins a reference's verses, each token with its verse number.
#   The weave is wovenOf's of the moment over his words and the Reader's Weave settings, never stored: a verse that has moved toward Greek is judged against the Greek
src/memorize/judge.ts   # judgeSaid / judgeTyped(target: Token[], heard) -> Judgement {score, passed, misses (token indexes), heardWords, asked}: learn-kit/recall's matchSequence over the target's texts (90% in order, extras free,
#   a token that folds to nothing is not asked); each token is matched in its own language, so a Greek token answered by its English is a miss (the Weave rule). judgeReading(target, VerseReadAnswer)
#   reads a Weave recall sent to verse-read: well-read passes, some-to-fix marks each focus word's token (index counts wordsOfText) and passes at a tenth or fewer, partial marks tokens past `reached` and fails, incomplete misses all.
#   asked(target) is the {text, lang} list recordRecall keeps. The folding is learn-kit/recall's fold, which src/services/greekWords.ts (bare) and src/services/reading.ts (normalWord) now use: no folder of their own
```
src/memorize/languages.ts # MemorizeLang 'en' | 'el' | 'weave'; languagesFor(level: GreekLevel): English always, Greek from Curious (GREEK_VIEW_FROM), the Weave from Dipping a toe (GREEK_WEAVE_FROM);
#   langName ('English', 'Greek', 'Weave'), isMemorizeLang. At 'Just English' only English is offered and nothing else is named
src/memorize/rung.ts      # rungFor(step) -> Rung {kind 'read' | 'gaps' | 'nothing', share}: step 0 read and say, 1..3 a quarter, half, three quarters of the words gone, 4 and 5 all gone with the first letters,
#   RARE_STEP (the 90-day check) from nothing; rungName for the screen. PROVISIONAL, the Governor to confirm
src/data/repositories/memorize.ts # verses on the schedule: kind 'verse' rows, id '<lang>:<canonical ref>' ('en:Rom.8.28'), one per verse per language, kept out of listDue()/countDue() with no kind (Review, Today, the pace and the summary do not count them);
#   memorize(ref, langs, now) / unmemorize(ref, lang?) / memorizedOf(refs) / memorizedRowOf(ref, lang) / listMemorized / listDueVerses / countDueVerses / nextDueVerse(now, except?) (the longest overdue, the session's Next verse); recordRecall(input, now) writes the `recalls` row (score, missed, asked tokens with their languages, rung, gap in days, how)
#   and the schedule row (a score of 0.9 or more is right) in one transaction and publishes 'memorize-due-changed'. The ONLY file that names db.recalls; unmemorize keeps the recalls (evidence)
src/memorize/commands.ts # how a verse enters and leaves memorizing: memorizeVerse({ref, langs}), unmemorizeVerse({ref, lang?}), memorizeList({listId}), unmemorizeList({listId}) -> {said, skipped?}, plain async functions over the memorize
#   repository and verseLists that the buttons call and the tutor-drives epic registers too (a screen never writes the repository itself). A language the Greek dial does not allow is dropped, English when none is left; an Old Testament
#   reference is skipped and named ('No Old Testament text in Lampas yet: Ps 62:1-2', printedRef/skippedLine); a list's commands act on the New Testament references it holds then (splitRefs), On in English, Off in every language
src/memorize/MemorizeControl.tsx # the one control a list row (compact) and the Verse view draw: 'Memorize' (a tap memorizes in English), 'Memorizing · English' (a tap opens the language sheet, a role=dialog with useSheetBack: a switch for each language
#   languagesFor(dial) allows plus any it is already memorized in, and Stop memorizing; at Just English no sheet, the tap stops it); the Verse view gives it the OSIS reference with the passage's range as one ('Rom.8.12-17'), a row only a New Testament reference
src/lists/VerseListScreen.tsx # (Memorize this list) the switch under Rename/Edit/Delete, aria-checked On when every New Testament reference is memorized in English, with the skipped line under it
src/memorize/useRecallHold.ts # (mw-fu7dqf.7) useRecallHold({lang, onHeard, onRecording, onUnavailable}) -> {talk, record}: how a recall is heard. 'en' is src/talk/useTalkHold.ts in en-US (not strict); 'el' is el-GR with voice-kit's strictLang
#   (DICTATION), so Greek is heard as Greek or not at all and the words reach onHeard(words) once, on release; a failure ('language-not-supported' or 'not-supported' -> 'no-greek-dictation' / 'no-dictation', 'network' -> 'offline',
#   'permission-denied' / 'no-microphone' -> 'no-microphone') is said once through onUnavailable(RecallUnavailable), and the session then lets him grade himself (I had it / Not yet, recorded how: 'self'). 'weave' starts no recogniser
#   (one recogniser hears one language): `record` ({listening, phase 'idle' | 'recording' | 'short' | 'dropped', press, release, drop}, a RecordBar's props) records over audio/recorder.ts recorderSeam as useReadChecks does, a hold under
#   SHORT_READING_MS is 'short' and sends nothing, and the Recording goes to onRecording. Both halves are always made (hooks cannot be conditional): the screen draws HeldTalkBar for 'en' / 'el', RecordBar for 'weave'
src/memorize/sendWeave.ts # sendWeaveRecall(ref, verses, woven, recording, {chapter?, ...AskOptions}) -> VerseReadAnswer for judgeReading: the verse-read request the reading check builds for a woven verse (weaveRecallRequest: weaveOfRecall = services/reading.ts
#   wovenReading's segments, or the English alone as one 'en' segment when nothing is woven yet; buildReadingRequest with the profile, summary, grammar, memory and the pronunciation), askVerseRead with the device key. `ref` is the printed heading
#   ('Romans 8:28', refs.ts NtVerses.heading), not the canonical. Offline or out of reach it rejects with askVerseRead's TutorError, which the session reads as self-grade. No grind change
src/memorize/MemorizeScreen.tsx # (mw-fu7dqf.8) the Memorize route (#/memorize): a MemorizeSession (keyed by language and reference) when the address names one, `#/memorize/<canonical ref>/<en|el|weave>` (nav/route.ts MEMORIZE_PATH,
#   memorizeSessionOf, memorizeSessionHash, openMemorizeSession(ref, lang, {replace}), closeMemorize); the bare address opens the next due verse in the place of its own entry, or says 'Nothing due' (the real home is s8's)
src/memorize/MemorizeSession.tsx # one session: the header (the reference, 'English · Half the words gone · step 3 of 7'), the verse (HiddenVerse), Hear it (runs.ts runsOfTokens: neighbouring tokens of a language are one Run, startAnswer under HEAR_ID, so the Weave is
#   read in its own languages; the button says 'Stop hearing it' while it reads), the hold at the foot (HeldTalkBar 'Hold to say it' for English and Greek, RecordBar for the Weave), the judgement ('Got it: 19 of 20 words', 'Not yet: 4 words missed',
#   only 'Got it' / 'Not yet' when he graded himself), 'Due <tomorrow | weekday | date>', 'I had it' / 'Not yet' once a note says the recall cannot be heard, and 'Next verse' (openMemorizeSession with replace: a run of sessions is one history
#   entry, so Back leaves it) or 'Done' (closeMemorize: a step Back, else Today). A judged verse shows every word with the missed ones marked, whatever the rung hid. Reports Verse, Language, Rung, Step, Last score and Due to the tutor
src/memorize/useSession.ts # useSession(ref, lang) -> {status: loading | ot | unknown | ready, ...}: loads versesOf, memorizeTarget over weaveSettingsNow (the weave of the moment), the schedule row (a verse not on it is step 0), hideWords(target.length, rung.share,
#   row.lastWhen) so the same words are gone each time; phases shown -> sending (a Weave recording is with the mill) -> judged; keep() writes recordRecall (rung = the step, missed words by text, asked tokens with their languages, how said | mill | self)
#   once and reads the row again for the due day; an empty hearing is ignored; a mill out of reach or a phone that cannot hear sets the note (UNAVAILABLE_NOTES) and the self-grade buttons. STEPS is 7 (steps 0..RARE_STEP)
src/memorize/HiddenVerse.tsx # the target token by token (data-token, data-blank, data-missed, lang="el" and the Greek face on a Greek token): a hidden word is a blank the width of the word, at share 1 its first letter is left, a missed word is marked in the Reader's miss colour
src/memorize/weaveSettings.ts # weaveSettingsNow() -> the Reader's Weave settings as the store holds them (the Greek dial's gate, the Weave, its grammar dial and order, solid and learning lemmas), view English: the one read of them outside useReaderSettings; the Reader's
#   plain-English-under-the-Weave choice does not apply, he asked to learn the verse in the Weave
src/memorize/due.ts # dueWords(due, now) -> 'Due today' | 'Due tomorrow' | 'Due <weekday>' (within six days) | 'Due <date>' by calendar days

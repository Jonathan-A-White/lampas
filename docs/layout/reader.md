# Layout: The Reader

Which file holds what, for the Preface, the chapter picker, the chapter buttons and swipe, the hash address and Back (src/nav/), links into Lampas, the long press on a word, the chips row, the Immersive reader, the reading layouts, the word sheet, the open chapter and the weave.

Moved word for word from CLAUDE.md's Layout (mw-gq6.485). A story that adds or changes a file of this area writes its note here, in the same form (the path, then `#` and what it holds; a continuation line starts `#   `), never in CLAUDE.md.

# Layout: Settings and study resources

Which file holds what, for src/settings/ (the registry, the rows, search, defineSetting, the goal setting) and src/resources/ (Strong's, Logos, Accordance and their links).

Moved word for word from CLAUDE.md's Layout (mw-gq6.485). A story that adds or changes a file of this area writes its note here, in the same form (the path, then `#` and what it holds; a continuation line starts `#   `), never in CLAUDE.md.

Two wordings of src/resources/ (two of its lines) survive here from union merges of CLAUDE.md; both were kept as they were. Read both: the code decides which is current.

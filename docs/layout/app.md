# Layout: The app shell, build, worker and updates

Which file holds what, for index.html, the manifest and precache, the build stamp, main.tsx and App.tsx, the list of screens, the event bus, appearance and fonts, config.ts, the error screen, the service worker, the update banner and What's new, src/ui/ basics and NextBar, public/, features/ and tests/.

Moved word for word from CLAUDE.md's Layout (mw-gq6.485). A story that adds or changes a file of this area writes its note here, in the same form (the path, then `#` and what it holds; a continuation line starts `#   `), never in CLAUDE.md.
